  
    SkillMatch JS

    Sobre o projeto

O SkillMatch JS é um mini-projeto feito em JavaScript puro.
Ele simula a análise de compatibilidade entre um candidato e vagas fictícias de Front-End Júnior.

O sistema compara as habilidades do candidato com os requisitos de cada vaga e mostra o percentual de compatibilidade.

    Objetivo

Praticar lógica de programação e conceitos básicos/intermediários de JavaScript.

    Funcionalidades

 Cadastro de um candidato
 Lista de vagas fictícias
 Cálculo de compatibilidade com cada vaga
 Listagem de habilidades encontradas
 Listagem de habilidades faltantes
 Classificação da compatibilidade
 Identificação da vaga mais compatível
 Recomendação de estudo
 Simulação de carregamento de vagas com Promise e async/await
